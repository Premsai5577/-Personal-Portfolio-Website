# Personal Portfolio Website Documentation

## Project Overview
This project is a personal portfolio website designed to introduce the developer, highlight technical skills, and provide contact information. The goal of the project is to create a simple, responsive, and professional portfolio using only HTML5 and CSS. The portfolio includes sections for About Me, Skills, and Contact, along with an internal navigation menu and a working contact form.

## Objectives
- Build a clean personal portfolio website
- Use semantic HTML5 structure correctly
- Include a professional introduction and contact details
- Add a skills section with list-based formatting
- Create a working contact form with validation
- Provide an attractive and responsive layout

## HTML Concepts Learned
HTML stands for HyperText Markup Language. It is used to structure the content of a web page. In this project, I learned how to use HTML tags and elements such as headings, paragraphs, links, images, buttons, and forms. I also learned the importance of document structure, including the doctype, html, head, and body tags.

The portfolio uses semantic HTML elements such as:
- header for the top section of the page
- nav for the navigation links
- main for the primary page content
- section for content blocks like About, Skills, and Contact
- footer for the bottom section of the page

I also used attributes such as:
- id for internal navigation anchors
- href for links
- src for image paths
- alt for image descriptions
- required for form validation

## Setup Instructions
1. Open VS Code on your computer.
2. Create a new folder named portfolio.
3. Inside the folder, create the following files:
   - index.html
   - README.md
   - images/profile.svg
4. Write the HTML structure in index.html.
5. Save the file and open it in a browser.
6. Use Live Server in VS Code for a better preview experience if needed.

## Technical Details
The project uses:
- Semantic HTML tags for structure and readability
- Internal anchor links for page navigation
- Form elements such as input and textarea
- Client-side validation using HTML required attributes
- CSS styling for layout, colors, spacing, and responsiveness

The architecture is simple and beginner-friendly. The HTML file contains the page structure and content, while the visual design is maintained in the external `style.css` file.

## Seven-Day Styling Plan
1. Day 1: Set up the external `style.css` file, link it to the HTML, and reset default styles.
2. Day 2: Add the Google Fonts import, typography rules, and a teal, coral, and yellow color scheme.
3. Day 3: Use CSS Grid and Flexbox for the hero, cards, navigation, and contact layout.
4. Day 4: Add hover states, transitions, focus styles, and card motion for interactive feedback.
5. Day 5: Add a mobile media query that stacks content, adjusts spacing, and keeps navigation readable.
6. Day 6: Style the form, profile image, cards, borders, shadows, and custom button components.
7. Day 7: Test the page at desktop and mobile widths, confirm the external stylesheet loads, and verify form validation.

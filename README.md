# Personal Portfolio Website

This project is a simple personal portfolio website built using HTML5 and CSS. It includes sections for About, Skills, and Contact, plus a responsive navigation bar and a working client-side contact form.

## Files
- `index.html` — the main portfolio page
- `images/profile.svg` — profile illustration used in the hero section

## How to run
1. Open `index.html` in any modern web browser.
2. Or use a local web server such as VS Code Live Server for preview.

## Features
- Semantic HTML structure
- Internal navigation links
- About, Skills, and Contact sections
- Responsive layout
- Form validation with JavaScript feedback
- Accessible alt text and image support
